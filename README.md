# Salon Chic Hair & Nails — website demo

Live demo: https://rolandvtonder.github.io/Salon-Chic-Hair-Nails-website-demo/

Eight pages (Home, Hair, Nails & Feet, Lashes, Wellness, Specials, About, Book & Contact) for Salon Chic Hair & Nails, 14 Moerdyk Street, Townsend Estate, Goodwood, Cape Town.

## Run it locally

```
npm install
npm run dev
```

`npm run build` type-checks and builds to `dist/`. Every push to `main` is built and published to GitHub Pages by `.github/workflows/deploy.yml`.

## Editing

- Prices, services, specials, hours and contact details: `src/content.ts`
- Photos and videos: `public/media/`

Built with Vite, React, TypeScript, Tailwind CSS v4 and Lenis. Stock photography and film from [Pexels](https://www.pexels.com).
